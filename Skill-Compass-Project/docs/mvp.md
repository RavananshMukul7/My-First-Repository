# SkillCompass MVP

## Problem

Developers often do not have a clear understanding of their actual technical
proficiency or which roles they are best suited for.

## Target User

Students and early-career developers looking for internships or entry-level
software engineering opportunities.

## MVP Features

1. GitHub repository collection
2. Technology extraction
3. Proficiency estimation
4. Skill-gap detection
5. Career-role recommendation

## Technology Stack

### Frontend
- React
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### AI
- LLM API

### External API
- GitHub API

## System Flow

GitHub User
    ↓
Repository Collection
    ↓
Technology Extraction
    ↓
Proficiency Estimation
    ↓
Skill Gap Detection
    ↓
Role Recommendation
